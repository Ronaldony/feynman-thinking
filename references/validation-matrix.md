# 주장 유형별 검증 행렬

먼저 주장 유형을 분류한다. 하나의 작업에 여러 유형이 섞이면 각각 따로 검사한다. 모든 검사를 억지로 적용하지 말고 관련 없는 항목은 `해당 없음(N/A)`으로 표시한다.

## 작업 수행 기준

검사를 **언급**한 것과 **수행**한 것을 구분한다.

| 표현 | 판정 |
|---|---|
| “성능 측정이 필요하다” | 검사 제안일 뿐, `미검증` |
| 입력·환경·지표·통과 기준을 정함 | 실행 가능한 검사 설계 |
| 실제 측정값이나 실행 로그를 제시함 | 수행된 검사 |
| 결과에 따라 모델·범위·확신을 수정함 | 검증 루프 완료 |

도구·자료가 있는데도 실행하지 않고 제안만 나열하면 과정 준수 실패다. 실행할 수 없으면 부족한 입력과 결과별 결론 변경 조건을 명시한다.

## 주장별 우선 검증

| 주장 유형 | 우선 수행할 작업 | 경쟁 설명·오류 | 대표 실패 신호 |
|---|---|---|---|
| 사실·최신 정보 | 1차 출처, 날짜·버전, 원주장, 독립 출처를 직접 확인 | 오래된 정보, 인용 전파, 정의 불일치 | 출처가 원주장을 지지하지 않음 |
| 자연에 대한 경험 주장 | 사전 예측, 측정, 대조, 재현, 오차와 대안 설명 | 선택 편향, 측정 오차, 사후 설명 | 반복 불가, 조건에 따라 효과 역전 |
| 인과 주장 | 시간 순서와 인과 그래프를 만들고 개입·준실험·교란을 비교 | 상관을 인과로 오인, 역인과, 자기선택 | 교란 통제 후 효과 소실 |
| 수학·논리 | 정의와 전제를 쓰고 단계별·독립 유도, 작은 반례, 경계를 확인 | 숨은 전제, 양화 범위 오류, 정의역 밖 사용 | 작은 반례, 유도 단계의 비약 |
| 근사 모델 | 정확한 기준선, 단위, 극한, 오차·상한, 보정항, 적용 영역 비교 | 모델과 현실 혼동, 유효 범위 초과 | 보정항이 본항과 동급, 경계에서 발산 |
| 소프트웨어 | 기준 구현, 단위·속성·통합 테스트, 실패 입력, 벤치마크와 자원 측정 | 행복 경로만 검사, 환경·캐시 편향 | 출력 불일치, 비결정성, 자원 폭증 |
| 설계·공학 | 요구사항 추적, 계산·프로토타입, 스트레스 테스트, 안전 여유와 FMEA | 정상 조건 편향, 단일 고장점, 센서 사각지대 | 허용 범위 밖에서 급격한 실패 |
| 예측 | 기준선, 시간 분리 후향 검증, 교정, 민감도, 업데이트 규칙 | 데이터 누수, 과적합, 기준율 무시 | 기준선보다 나쁨, 확신과 적중률 불일치 |
| 연구 종합 | 검색 범위, 포함·제외 기준, 1차 연구, 표본 중복, 품질·이질성 평가 | 권위·인용 수 편향, 출판 편향 | 결론이 연구 하나나 특정 표본에 의존 |
| 전략·의사결정 | 목표 함수, 가역성, 기준선, 대안 시나리오, 작은 실험과 중단 조건 | 성공 사례 모방, 매몰비용, 선택 기준 은폐 | 핵심 전제가 바뀌면 순위 역전 |
| 정책·사회·조직 | 인과 가정, 이해관계자, 인센티브, 집단별 효과, 윤리·실행 가능성 | 인간 변수 삭제, 평균 효과만 강조, Goodhart 효과 | 회피 행동, 집단별 역효과, 제도 충돌 |
| 가치·우선순위 | 사실과 가치 전제를 분리하고 권리·제약·트레이드오프를 공개 | 가치 판단을 사실처럼 위장 | 같은 사실에서 가치에 따라 선택이 달라짐 |
| 설명·학습 | 쉬운 작동 설명, 대안 표현, 작은 예제와 정밀한 근거의 동치성 확인 | 비유가 메커니즘을 대체, 용어 암기 | 예외·경계에서 설명이 무너짐 |

## 공통 정량 검사

적용되는 경우 다음을 직접 확인한다.

- 단위와 차원이 맞는가?
- 부호와 방향이 상식적 극한에서 맞는가?
- 규모가 현실적인 범위인가?
- 0, 1, 무한대, 최대·최소 같은 경계에서 무엇이 생기는가?
- 매개변수 하나를 바꿀 때 결론이 얼마나 변하는가?
- 초기·경계 조건과 극한 순서에 민감한가?
- 계산·메모리·시간·데이터 비용이 규모에 따라 어떻게 증가하는가?
- 오차가 다음 단계와 최종 판단으로 어떻게 전파되는가?
- 평균값이 꼬리·분포·집단별 효과를 숨기지 않는가?

정량 검사가 의미 없는 가치 판단이나 순수한 편집 작업에는 `N/A`를 사용할 수 있다. 숫자를 만들기 위해 근거 없는 점수나 확률을 발명하지 않는다.

## 판별력 검사

검사마다 다음을 묻는다.

1. 현재 모델이 이 결과를 예측하는가?
2. 경쟁 모델도 같은 결과를 예측하는가?
3. 결과가 반대이면 실제로 결론을 수정할 것인가?
4. 검사 조건이 모델의 적용 범위 안에 있는가?
5. 측정 오차가 모델 차이보다 작은가?

2번이 `예`, 3번이 `아니오`이면 강한 검증이 아니다.

## 증거 강도

증거를 인용 수나 문장 자신감이 아니라 다음 기준으로 평가한다.

1. **직접성**: 주장 자체를 측정·유도하는가?
2. **독립성**: 같은 자료나 가정을 반복하지 않는가?
3. **판별력**: 경쟁 설명을 구별하는가?
4. **재현성**: 다른 사람이 같은 결과를 얻을 수 있는가?
5. **적용성**: 현재 문제의 조건과 맞는가?
6. **정확도**: 오차와 한계가 알려져 있는가?
7. **결론 변화 가능성**: 결과가 실제 판단을 바꿀 수 있는가?

## 검증 결과 표기

- **통과**: 사전에 정한 기준을 만족했다.
- **실패**: 기준을 명확히 위반했다.
- **미검증**: 필요한 자료·도구·실행이 없어 확인하지 못했다.
- **판별력 부족**: 현재 모델과 경쟁 모델이 같은 결과를 예측한다.
- **범위 밖**: 검사 조건이 모델의 적용 영역을 벗어났다.
- **해당 없음(N/A)**: 주장 유형과 무관하다. 이유를 짧게 적는다.

`N/A`는 적용 가능한 검사를 피하기 위해 사용할 수 없다. 실패·미검증·판별력 부족은 결론의 범위, 확신 또는 다음 행동에 연결한다.
