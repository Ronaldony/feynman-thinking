# 주장 유형별 검증 행렬

먼저 주장 유형을 분류한다. 하나의 작업에 여러 유형이 섞이면 각각 따로 검사한다.

| 주장 유형 | 우선 검증 | 자주 생기는 오류 | 실패 신호 |
|---|---|---|---|
| 사실·기술 | 1차 출처, 날짜·버전, 독립 출처, 직접 관찰 | 오래된 정보, 인용 전파, 정의 불일치 | 출처가 원주장을 지지하지 않음 |
| 자연에 대한 경험 주장 | 사전 예측, 측정, 대조군, 재현, 반례, 대안 설명 | 선택 편향, 측정 오차, 사후 설명 | 반복 불가, 효과가 조건에 따라 역전 |
| 인과 주장 | 시간 순서, 개입·준실험, 교란 요인, 대안 인과 그래프 | 상관을 인과로 오인, 역인과 | 교란 통제 후 효과 소실 |
| 수학·논리 | 전제 명시, 단계별 유도, 독립 유도, 특수·경계 사례, 모순 검사 | 숨은 전제, 양화 범위 오류 | 작은 반례, 정의역 밖 사용 |
| 근사 모델 | 기준해, 차원, 극한, 오차·상한, 보정항, 적용 영역, 데이터 비교 | 모델과 현실 혼동, 유효 범위 초과 | 경계에서 발산, 보정항이 본항과 동급 |
| 소프트웨어 | 단위·통합·속성 테스트, 기준 구현, 실패 입력, 성능·자원 측정 | 행복 경로만 검사, 환경 의존 | 동일 입력 비결정성, 자원 폭증 |
| 설계·공학 | 요구사항 추적, 프로토타입, 스트레스 테스트, 안전 여유, FMEA | 정상 조건 편향, 단일 고장점 | 허용 범위 밖에서 급격한 실패 |
| 예측 | 기준선, 시간 분리 후향 검증, 교정, 민감도, 시나리오, 업데이트 규칙 | 데이터 누수, 과적합, 확률 비교정 | 기준선보다 나쁨, 확신과 적중률 불일치 |
| 연구 종합 | 검색 범위, 포함·제외 기준, 1차 연구, 품질·이질성 평가 | 권위·인용 수 편향, 중복 표본 | 결론이 특정 연구 하나에 의존 |
| 정책·사회 판단 | 도메인 연구, 이해관계자, 인센티브, 분배·형평, 윤리, 실행 가능성 | 인간 변수 삭제, 평균 효과만 강조 | 집단별 역효과, 회피 행동, 제도 충돌 |
| 가치·우선순위 | 가치 전제 명시, 이해관계자 합의, 트레이드오프, 권리·제약 | 사실 판단처럼 위장 | 동일 사실에서도 가치에 따라 선택이 달라짐 |

## 공통 정량 검사

가능한 경우 다음을 적용한다.

- 단위와 차원이 맞는가?
- 부호와 방향이 상식적 극한에서 맞는가?
- 규모가 현실적 범위인가?
- 0, 1, 무한대, 최대·최소 같은 경계에서 무엇이 생기는가?
- 매개변수 하나를 바꿀 때 결론이 얼마나 변하는가?
- 초기 조건과 극한을 취하는 순서에 민감한가?
- 계산·메모리·시간·데이터 비용이 규모에 따라 어떻게 증가하는가?
- 오차가 다음 단계로 어떻게 전파되는가?

## 증거 강도 판단

증거를 인용 수가 아니라 다음 기준으로 평가한다.

1. **직접성**: 주장 자체를 측정·유도하는가?
2. **독립성**: 동일 자료나 동일 가정을 반복하지 않는가?
3. **판별력**: 경쟁 설명을 구별하는가?
4. **재현성**: 다른 사람이 같은 결과를 얻을 수 있는가?
5. **적용성**: 현재 문제의 조건과 맞는가?
6. **정확도**: 오차와 한계가 알려져 있는가?
7. **결론 변화 가능성**: 이 증거가 실제 판단을 바꿀 수 있는가?

## 검증 결과 표기

- **통과**: 사전에 정한 기준을 만족함
- **실패**: 기준을 명확히 위반함
- **미검증**: 필요한 검사나 자료가 없음
- **판별력 부족**: 여러 모델이 같은 결과를 예측함
- **범위 밖**: 검사 조건이 모델의 적용 영역을 벗어남

검증 실패를 숨기지 말고 결론의 범위·확신·모델 선택에 연결한다.
