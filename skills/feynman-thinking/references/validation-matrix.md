# 주장 유형별 검증 행렬

먼저 주장 유형을 분류한다. 하나의 작업에 여러 유형이 섞이면 각각 따로 검사한다. 모든 항목을 억지로 적용하지 말고, 결론을 바꿀 수 있는 검사만 선택한다.

## 판정 상태

- **통과**: 사전에 정한 기준을 만족함
- **실패**: 기준을 명확히 위반함
- **미검증**: 필요한 자료·실행·도구가 없음
- **판별력 부족**: 경쟁 모델도 같은 결과를 예측함
- **범위 밖**: 검사 조건이 모델의 적용 영역을 벗어남
- **N/A**: 이 주장 유형이나 현재 결정에는 실질적으로 관련 없음

`N/A`는 점수 손실을 피하기 위한 표시가 아니다. 왜 적용되지 않는지 한 문장으로 적는다.

## 유형별 우선 검사

| 주장 유형 | 필수에 가까운 검사 | 조건부 검사 | 자주 생기는 오류 | 실패 신호 |
|---|---|---|---|---|
| 사실·최신 정보 | 1차 출처, 날짜·버전, 직접 인용의 지지 여부 | 독립 출처, 현장 관찰 | 오래된 정보, 인용 전파, 정의 불일치 | 출처가 원주장을 지지하지 않음 |
| 자연에 대한 경험 주장 | 측정, 대조, 재현, 오차, 대안 설명 | 사전 예측, 반례, 메타분석 | 선택 편향, 측정 오차, 사후 설명 | 반복 불가, 조건에 따라 효과 역전 |
| 인과 주장 | 시간 순서, 교란 요인, 대안 인과 그래프 | 개입·준실험, 음성 대조, 민감도 | 상관을 인과로 오인, 역인과 | 교란 통제 후 효과 소실 |
| 수학·논리 | 전제·정의역, 단계별 유도, 모순 검사 | 독립 유도, 특수·경계 사례 | 숨은 전제, 양화 범위 오류 | 작은 반례, 정의역 밖 사용 |
| 근사 모델 | 정확 기준, 차원, 유효 범위, 오차·보정 | 극한, 기준해, 데이터 비교 | 모델과 현실 혼동, 범위 초과 | 보정항이 본항과 동급, 경계에서 발산 |
| 소프트웨어 | 기준 구현, 단위·통합·속성 테스트, 실패 입력 | 성능·메모리·동시성 측정 | 행복 경로만 검사, 환경 의존 | 비결정성, 정확성 불일치, 자원 폭증 |
| 설계·공학 | 요구사항 추적, 고장 모드, 스트레스 조건 | 프로토타입, 안전 여유, FMEA | 정상 조건 편향, 단일 고장점 | 허용 범위 밖에서 급격한 실패 |
| 예측 | 기준선, 시간 분리 검증, 업데이트 규칙 | 교정, 민감도, 시나리오 | 데이터 누수, 과적합 | 기준선보다 나쁨, 확신과 적중률 불일치 |
| 연구 종합 | 검색 범위, 포함·제외 기준, 1차 연구, 중복 표본 | 품질·이질성·출판 편향 평가 | 권위·인용 수 편향 | 결론이 특정 연구 하나나 공유 데이터에 의존 |
| 정책·사회 판단 | 이해관계자, 인센티브, 제도, 분배 효과, 윤리 | 인과 추정, 시뮬레이션, 실행 실험 | 인간 변수 삭제, 평균 효과만 강조 | 집단별 역효과, 회피 행동, 제도 충돌 |
| 가치·우선순위 | 가치 전제, 권리·제약, 트레이드오프 | 이해관계자 합의, 다기준 비교 | 가치 판단을 사실처럼 위장 | 같은 사실에서도 가치에 따라 선택 변화 |
| 설명·교육 | 작동 과정, 누락된 인과 단계, 쉬움-정밀함 일치 | 장난감 사례, 비유, 그림 | 용어 치환, 비유가 메커니즘 대체 | 쉬운 설명과 정밀 설명이 서로 모순 |

## 파인만식 공통 검사

다음은 모든 과제에 기계적으로 요구되는 체크리스트가 아니다. 관련성이 있을 때 우선 검토한다.

### 실체 검사

- 핵심 명칭을 실제 대상·입력·출력·상태 변화로 바꿨는가?
- 관찰하거나 조작할 수 없는 정의가 결론을 떠받치고 있지 않은가?

### 표현 검사

- 첫 표현 외의 다른 표현을 검토했는가?
- 대안 표현이 새로운 가정, 대칭, 경계 또는 누락 변수를 드러냈는가?
- 두 표현이 동치라고 가정했다면 실제로 같은 귀결을 내는가?

### 직접 점검

- 단위와 차원이 맞는가?
- 부호와 방향이 상식적 극한에서 맞는가?
- 규모가 현실적인 범위인가?
- 가장 작은 사례나 경계에서 무엇이 생기는가?
- 기준선 또는 손계산과 일치하는가?
- 자원 비용이 규모에 따라 어떻게 증가하는가?

### 판별력 검사

- 이 증거가 경쟁 설명을 실제로 구별하는가?
- 어떤 결과가 나오면 현재 모델을 약화하거나 폐기할 것인가?
- 검사 결과가 결론을 바꿀 수 있는가?

## 증거 강도 판단

증거를 인용 수가 아니라 다음 기준으로 평가한다.

1. **직접성**: 주장 자체를 측정·유도하는가?
2. **독립성**: 동일 자료나 동일 가정을 반복하지 않는가?
3. **판별력**: 경쟁 설명을 구별하는가?
4. **재현성**: 다른 사람이 같은 결과를 얻을 수 있는가?
5. **적용성**: 현재 문제의 조건과 맞는가?
6. **정확도**: 오차와 한계가 알려져 있는가?
7. **결론 변화 가능성**: 이 증거가 실제 판단을 바꿀 수 있는가?

## 검사 선택 규칙

1. 정의 모순, 단위, 부호, 작은 반례처럼 싸고 치명적인 검사부터 수행한다.
2. 핵심 가정을 직접 공격하는 검사를 다음으로 둔다.
3. 경쟁 모델을 구별하지 못하는 성공 사례의 증거 강도를 낮춘다.
4. 고비용 검사는 결론 변화 가능성과 오류 비용이 충분히 클 때 수행한다.
5. 검증 실패를 결론의 범위·확신·모델 선택에 연결한다.
