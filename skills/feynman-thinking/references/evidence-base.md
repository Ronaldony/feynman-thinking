# 학술 근거 지도

## 사용 원칙

이 자료는 파인만의 이름을 권위로 사용하기 위한 목록이 아니다. 각 논문에서 관찰되는 연구 행동을 제한적으로 일반화한 근거 지도다.

- **관찰**: 논문에서 실제로 확인되는 작업 행동
- **운영 규칙**: 스킬에 옮긴 일반화
- **일반화 한계**: 논문 하나에서 과도하게 추론하지 않기 위한 경계

## 명시적 과학관을 위한 보조 자료

다음 자료는 연구 논문이 아니라 파인만이 과학적 태도를 직접 설명한 강연·교육 자료다.

1. Feynman, “The Value of Science,” *Engineering and Science* 19(3), 13–15 (1955): 의심과 불확실성의 가치.
2. Feynman, “Cargo Cult Science,” Caltech commencement address (1974): 결과에 불리한 조건까지 공개하는 과학적 진실성.
3. Feynman, Leighton & Sands, *The Feynman Lectures on Physics*, Vol. I, Ch. 1–2: 관찰·실험과 물리 법칙의 근사성.

## 스킬 설계에 대한 근거 등급

- **강한 근거**: 불리한 증거 공개, 불확실성 명시, 관찰·실험과의 비교, 정확과 근사의 구분.
- **중간 근거**: 표현 전환, 직접 계산, 적절한 자유도 선택, 자원 제약 검토. 여러 논문에서 반복되지만 고정 절차로 명시되지는 않음.
- **현대적 확장**: 위험 기반 검증 수준, 사회·정책 윤리 가드레일, 소프트웨어 테스트 행렬, 표준화된 작업 문서. 유용성을 위해 추가했으며 파인만의 고유 규칙으로 귀속하지 않음.

## 업데이트 원칙

새 논문 분석이나 실제 사용 평가가 기존 일반화와 충돌하면 다음 순서로 수정한다.

1. 귀속을 약화하거나 제거한다.
2. 적용 범위를 좁힌다.
3. 예외와 실패 조건을 추가한다.
4. 실제 성능 개선이 없는 규칙은 삭제한다.
